# 初心者向けHTMLビルダー (初心者向けWebサイト制作ツール)

HTMLやCSSの知識がなくても、直感的な操作とブロック配置で複数ページのレスポンシブWebサイトを作成し、完成したHTML一式（ZIP）を出力できるWebアプリケーションです。

## 主な機能

- **業界別テンプレート**: 飲食店、士業・コーポレート、サロン・美容、採用・LPなど多彩なプリセット
- **ビジュアル編集**: クリックしてその場で文字修正、ドラッグ＆ドロップによるブロック並び替え
- **複数ページ対応**: `index.html`（トップ）に加え、`about.html`、`service.html` 等の複数ページを一括管理
- **自動画像圧縮**: アップロードされた写真を長辺1600px・WebP形式に自動最適化
- **動く背景プリセット**: 軽量なループ動画背景・オーバーレイ効果
- **自動保存 & 復元**: ローカルストレージによる自動保存インジケーター搭載
- **ZIPエクスポート & 公開ガイド**: ワンクリックで全ページ・画像をまとめたZIPを出力、初心者向けレンタルサーバー公開マニュアル（PDF）付き

## GitHub Pagesへのデプロイ手順

本リポジトリを GitHub Pages に公開する場合は、未ビルドのソースファイルではなく**ビルド済みファイル（`dist` フォルダ）**をデプロイしてください。

### 方法1: 手動ビルド & 公開
```bash
# 依存関係のインストール
npm install

# 本番用ビルド (dist フォルダに成果物が生成されます)
npm run build
```
生成された `dist` フォルダ内のファイル（`index.html`、`assets/` 等）を GitHub Pages の公開ブランチ（例: `gh-pages`）に配置してください。

### 方法2: GitHub Actions による自動デプロイ
GitHub リポジトリの **Settings > Pages > Build and deployment** の Source にて「**GitHub Actions**」を選択し、Vite / Static HTML ワークフローを設定してください。
